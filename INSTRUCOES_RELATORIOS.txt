A) QUANDO SAI UMA NOVA COMPETÊNCIA (Ex: Saiu Outubro no TabNet)
------------------------------------------------------------------------------
1. Execute o script de Extração (Demora ~40min):
   & python extrator_tabnet.py
   
   * O que ele faz: Baixa todos os arquivos CSV (Ricos com 15 colunas) do DATASUS.
   * Onde salva: Pasta "TABNET_Export".

B) ATUALIZAÇÃO ROTINEIRA (PROCESSAMENTO E PUBLICAÇÃO)
------------------------------------------------------------------------------
Se você já baixou os arquivos ou quer apenas recalcular os dados:

1. Execute o script Mestre:
   & python ATUALIZAR_TUDO.py

   * O que ele faz (Automaticamente):
     1. Atualiza dados do SISREG (Regulação).
     2. Processa os arquivos do TabNet (Faturamento) -> Gera dados_tabnet.json.
     3. Executa o Upload Manager -> Envia tudo para o GitHub.

C) SOLUÇÃO DE PROBLEMAS (TABNET)
------------------------------------------------------------------------------
ERRO: "Mês X com dados zerados ou faltando colunas"
-> Significa que o arquivo na pasta 'TABNET_Export' é do tipo "Pobre".
-> Solução: Apague o arquivo .csv desse mês específico e rode o 'extrator_tabnet.py' novamente (ou baixe manualmente marcando TODAS as colunas no TabNet e salvando como .csv).

ERRO: "Login Inválido"
-> Edite o arquivo 'login.html' para alterar usuário/senha.
