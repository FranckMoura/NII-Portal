Como Remover Senha de Edição no Excel (Método XML)

Este tutorial explica passo a passo como desbloquear abas protegidas de um arquivo .xlsx mantendo toda a formatação original, alterando a estrutura interna do arquivo.

Passo a Passo

  1. Faça um backup: Antes de começar, crie uma cópia do arquivo original por segurança.
  2. Altere a extensão: Renomeie a cópia do arquivo de .xlsx para .zip.
    *Se o Windows não mostrar a extensão, vá na guia "Exibir" e marque a opção "Extensões de nomes de arquivos".
  3. Extraia os arquivos: Clique com o botão direito no arquivo .zip e escolha "Extrair Tudo..." para uma nova pasta.
  4. Localize a planilha bloqueada: Navegue até a pasta extraída, abra a pasta xl e, em seguida, a pasta worksheets. Aqui você verá arquivos como sheet1.xml, sheet2.xml.
  5. Edite o arquivo XML:
    • Clique com o botão direito na planilha que deseja desbloquear e abra com o VS Code.
    • Pressione Ctrl + F e pesquise por sheetProtection.
    • Você encontrará uma tag parecida com esta: <sheetProtection algorithmName="SHA-512" hashValue="..." saltValue="..." spinCount="100000" sheet="1" objects="1" scenarios="1"/>
    • Exclua a tag inteira (começando no < antes de sheetProtection até o fechamento />).
    • Salve o arquivo (Ctrl + S) e feche o VS Code.
  6. Recrie o arquivo ZIP: Volte para a pasta principal onde você extraiu tudo. Selecione todos os arquivos e pastas ali dentro (_rels, docProps, xl, [Content_Types].xml). Clique com o botão direito e escolha "Compactar para arquivo ZIP".
  7. Restaure a extensão original: Renomeie o novo arquivo compactado de .zip de volta para .xlsx.
Pronto! Ao abrir este novo arquivo no Excel, a aba estará completamente livre para edição e com a mesma estrutura visual de antes.
